\# 👻 GhostShell AI — A Spooky Local AI Assistant



> A friendly AI ghost that explains terminal commands with a spooky twist.



GhostShell AI is a beginner-friendly Python project powered by \*\*Ollama and Gemma 3 1B\*\*. It accepts user input, explains terminal commands in simple English, and generates creative spooky responses using a locally running AI model.



This project is being developed for the \*\*Hacktoberfest Open-Source AI Challenge — Week 4: Ghost in the Machine\*\*.



\## ✨ Features



\- 👻 Spooky AI assistant with a Halloween-inspired personality.

\- 🤖 AI-generated responses using Gemma 3 1B.

\- 💻 Explains terminal commands such as `git status`.

\- 📝 Provides simple explanations that beginners can understand.

\- 🕸️ Generates creative, mysterious comments related to user input.

\- 📴 Supports local inference without an internet connection after the model has been downloaded.

\- 🔒 Designed to process prompts through a locally running Ollama service instead of a hosted AI API.



\## 🛠️ Technologies Used



\- \*\*Python\*\* — application logic

\- \*\*Ollama\*\* — local AI model runtime

\- \*\*Gemma 3 1B\*\* — open-weight language model

\- \*\*Ollama Python library\*\* — connects Python to Ollama



\## ⚙️ How It Works



1\. The user enters a terminal command or a question.

2\. Python prepares a prompt for GhostShell.

3\. Ollama sends the prompt to the locally running Gemma model.

4\. The model generates an explanation and a spooky response.

5\. GhostShell displays the response in the terminal.



\*\*Important:\*\* GhostShell treats the entered command as text. It does not need to execute the user's terminal commands to explain them.



\## 🚀 Getting Started



\### Prerequisites



Install the following:



\- Python 3

\- Ollama for Windows

\- An internet connection for the initial model download



Download Ollama: https://ollama.com/download



\### 1. Download the model



Open Command Prompt and run:



```bash

ollama run gemma3:1b

```



Wait for the model download to finish. Test it by entering a simple prompt. Type `/bye` to leave the model chat.



\### 2. Open the project folder



```bash

cd "%USERPROFILE%\\Desktop\\ghostshell-ai"

```



\### 3. Create a virtual environment



```bash

py -m venv .venv

```



\### 4. Install the Python dependency



```bash

.venv\\Scripts\\python -m pip install ollama

```



\### 5. Run GhostShell AI



Make sure Ollama is running, then execute:



```bash

.venv\\Scripts\\python app.py

```



Follow the on-screen instructions to interact with GhostShell. Type `exit` to leave the application.

\## 🌐 Why Open-Weight AI?



GhostShell uses a locally running open-weight model instead of depending on a hosted AI API for every message.



\- \*\*Offline capability:\*\* After downloading the model, GhostShell can generate responses without an internet connection, provided the local runtime and model are available.

\- \*\*Privacy:\*\* Prompts can stay on the local machine when using the local model and runtime, without sending them to a hosted AI inference API.

\- \*\*Model flexibility:\*\* Developers can experiment with compatible models and customize the assistant's prompt.

\- \*\*Cost control:\*\* No per-request hosted AI API charge is required for local inference, although hardware, electricity, and storage have costs.

\- \*\*Learning:\*\* The project demonstrates how Python applications can communicate with a local language model.



Gemma is an open-weight model. Check its applicable license terms before redistribution or other use.
